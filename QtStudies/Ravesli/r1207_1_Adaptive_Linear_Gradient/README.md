Чтобы сделать код максимально быстрым, нужно перенести создание градиента из метода paintEvent в конструктор класса, а сам градиент сохранить как поле класса.

В таком случае тяжелые математические расчеты точек и цветов градиента выполнятся всего один раз (при старте программы), а в paintEvent будет происходить только мгновенная отрисовка.

## Почему этот подход идеален?

- Нулевые утечки памяти: Градиент является частью объекта MyWidget. Когда удалится виджет (например, закроется окно), автоматически и без вашего участия очистится память градиента.

- Максимальная производительность: Метод paintEvent теперь работает «на максималках», выполняя только саму отрисовку пикселей.

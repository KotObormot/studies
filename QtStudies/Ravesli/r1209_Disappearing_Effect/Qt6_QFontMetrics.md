# Как исправить в Qt6 ошибку no member 'width' in 'QFontMetrics'

- [AI](https://share.google/aimode/5Knshs9U2ZFxUKvzR)

Чтобы исправить ошибку no member 'width' in 'QFontMetrics' в Qt6, вам нужно заменить устаревший метод width() на horizontalAdvance().

В Qt6 метод width() был окончательно удален, так как его название вводило в заблуждение: он возвращал расстояние до следующего символа при рисовании строки (шаг), а не реальную физическую ширину пикселей в рамке. [1, 2] 

## Как исправить код

В зависимости от вашей задачи выберите один из двух вариантов:

### Вариант 1. Если вам нужен шаг строки (для большинства задач)

В 95% случаев метод width() использовался для расчета длины строки, чтобы разместить следующий элемент текста. Замените его на horizontalAdvance(): [1, 2] 

    // Было в Qt5 (вызовет ошибку в Qt6):
    int w = fontMetrics.width("Ваш текст");

    // Стало в Qt6:
    int w = fontMetrics.horizontalAdvance("Ваш текст");

### Вариант 2. Если нужна точная геометрическая ширина (с учетом наклона текста)

Если вы используете курсив (Italic) или специфические шрифты, где буквы могут выходить за стандартные границы шага, используйте boundingRect(): [1, 2] 

    // Возвращает точную ширину прямоугольника, в который вписан текстint 
    w = fontMetrics.boundingRect("Ваш текст").width();
